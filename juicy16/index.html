Juicy16

A free 16-channel SoundFont and DLS player for macOS (AU/VST3) and Windows (VST3). I built it to play multichannel game MIDI in my DAW without setting every patch by hand. Load one sound bank, send it MIDI, and let the file choose the instruments.

One bank, sixteen channels

The MIDI handles the patch changes. I can still adjust the mix.

  • DLS, SF2 and SF3. One loaded file supplies the instruments for all sixteen channels.
  • Automatic patch changes. Bank Select and Program Change messages choose each channel’s instrument, including changes mid-song.
  • Hands-on control. Instrument selection, volume, pan, mute, solo and independent trim for each channel, plus master trim, reverb and chorus.
  • One stereo output. Route the MIDI channels into one instance in your DAW. Juicy16 does not open or play MIDI files itself.

New in 1.0.0-beta.1: Linear interpolation by default, full-range stereo DLS pan, ignored Balance CC8/CC40, and a fix for silent channel 10 kits after Bank Select.

Get a MIDI playing

  1. Install the plugin. On Windows, run the Setup EXE or extract the portable ZIP and copy the complete Juicy16.vst3 folder into your DAW’s VST3 folder. On macOS, unzip and right-click install_macos.command → Open, then choose AU, VST3 or both. Restart your DAW and rescan. See the Windows guide or macOS guide.
  2. Load the matching bank. Insert Juicy16 as an instrument and choose your DLS, SF2 or SF3 file. The sound bank supplies the samples; the MIDI supplies the notes.
  3. Keep the MIDI channels intact. Send channels 1–16 to that instance. If your DAW forces every part onto channel 1, the instruments will collide. Channel 10 defaults to GM percussion.
  4. Play from the beginning. Keep the file’s Bank Select, Program Change and controller events so its initial setup reaches the plugin.

About this beta

The Windows build passed local automated checks and my testing. The Mac AU passes Apple’s validator. Clean minimum-OS installs and a complete DAW compatibility matrix remain unverified; see the release notes for the testing limits.

  • Chorus is available and off by default. It follows the bank’s routing and MIDI CC93.
  • Older plugin builds cannot read the new project-state format. Keep a separate project copy if you need to roll back.
  • FluidSynth’s internal timing delay and known small leaks remain. Keep a backup of important projects.

I recommend testing with a copy of your project. Full release notes · Source on GitHub
